Tech Stack Used
-React-Vite
-Material-UI (MUI
- Recharts
- React Router
- Axios
- EmailJS
- CSS
- Local Storage
- No server or cloud database is used.

Working Flow

1. Authentication & Registration
   - Vendors and customers can sign up and log in.
   - Credentials and user data are stored in local storage.

2. Vendor Side
   - Vendors can create event packages and  services.
   - Vendors can view bookings, manage events, and see analytics on their dashboard.
   - Vendors can send invitations to customers (using EmailJS if set up).

3. Customer Side
   - Customers can browse available event packages and services.
   - Customers can book events or services and view their bookings.
   - Customers can receive notifications and invitations.
-Customer can give feedback .

4. Data Management
   - All data is managed locally in the browser.
   - If you refresh or clear browser storage, data will be lost.
 Important: You must add sample data (vendors, events, etc.) manually through the app’s UI for testing, as there is no preloaded or server-side data.
